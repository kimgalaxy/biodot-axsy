회수·재배치 → 현장 기록 → 대시보드 갱신

위험 계산·폴링은 스크립트로 실행하고, 설명·요약에 AI를 사용합니다.

D / 메타 · 네이버 · 구글 광고 탄력적 운용

매체 전담 3명(메타·구글·네이버) + 퍼포먼스 총괄 → 분석·캠페인설계·세팅안 → 승인·집행 → 실험·개선·확대
광고 API/보고서·전환·재고 분석 · 월 총예산·변경 폭 검증 · 캠페인/예산/소재/랜딩 이력 · 네이버 검색/성과형 DA 별도 어댑터 · 미지원 기능은 수동 집행

권한 경계 · 사업자 분리

공개 데이터와 사내·HACCP 자료는 스키마·버킷·역할로 분리. 글리스코 코리아는 별도 사업자 권한·키 적용. service_role은 RLS를 우회하므로 AI에 공용 키를 배포하지 않고, 직무별 허용 API·제한된 DB 역할로 접근을 통제합니다.

실패 복구 · 운영 관측 / 구현 보완

외부 이벤트 서명·중복 확인 → 원장 저장 → 비동기 실행. 작업 ID로 로그·승인·비용 추적. 일반 작업은 횟수 제한 재시도, ERP 결과 불명은 수동 대사. 실패 작업·동기화 지연·호출 한도·백업 복원 여부를 운영 화면에서 확인합니다.

배포 · 확장 범위

개발/검증/운영 환경과 비밀 키 분리 · Git/CI → Workers·VM 배포 · DB 마이그레이션 버전 관리. 앱·게임·하이브리드 RAG·통화 실시간 개입은 후속 범위. 모델·OAuth·전화 사업자 연결 조건은 구현 시 공식 문서로 검증합니다.
